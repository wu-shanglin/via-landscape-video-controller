# Via 横屏视频控制器

> 为 Via 浏览器中的网页视频提供 iOS 风格的横屏操作界面：视频控制、手势快进/快退、精细进度拖动，以及 VTT / 精灵图缩略图预览。

**项目类型：** UserScript（油猴脚本） · **作者：** 小桐雨 · **语言：** JavaScript · **无需构建**

> [!IMPORTANT]
> 本仓库收录的是用户提供的原始脚本，代码内容未经功能修改。脚本元信息 `@version` 为 `1.0`，设置界面内部显示 `v6.1`；两者目前不一致。后续发布正式版本时建议统一版本号，并设置维护流程。

## 功能介绍

- **横屏接管 / 竖屏恢复：** 检测到可操作的 HTML5 视频时，在横屏展示自定义控制层；退出横屏时尝试恢复原始播放控件。
- **基础播放控制：** 播放 / 暂停、前后 10 秒跳转、视频全屏操作、缓冲及播放进度显示、自动隐藏控制层。
- **大触控区域：** 播放 / 暂停按钮更大，进度条具有至少 72px 的触控热区，降低误触概率。
- **画面左右滑动：** 右滑快进、左滑快退；滑动过程中预览目标时间，松手后再执行跳转。灵敏度可在 90、120、180、240、300 秒 / 屏之间选择。
- **长按倍速：** 视频播放中长按约 450ms 暂时切换至 2× 或 3×，松手恢复此前倍速。
- **精细进度拖动：** 在进度条横向拖动时，向上移动手指可逐级降低灵敏度，便于精确定位。
- **缩略图预览：** 尝试读取 WebVTT 缩略图索引、单图或精灵图，或复用网站原有的预览资源。识别未就绪时会间隔重试。
- **按域名保存预览布局：** 将学习到的精灵图布局保存在本地；横竖屏切换时尽量复用当前视频的识别结果，也可以手动重新学习。
- **分组设置面板：** 外观、手势、预览三个标签页，可调整宽度、高度、边距、自动隐藏时间、滑动灵敏度等。

## 安装

### Via 浏览器

1. 下载仓库中的 [`via-landscape-video-controller.user.js`](./via-landscape-video-controller.user.js)，或打开该文件复制全部脚本代码。
2. 在支持用户脚本的 Via 浏览器中，进入**设置 → 脚本**（具体路径随平台及版本可能不同）。
3. 新建脚本并粘贴完整代码，或使用浏览器提供的脚本导入功能；保存并启用。
4. 打开 HTTPS 视频网页，开始播放视频后切换横屏。
5. 轻触视频画面显示控件，点击右上角 **⚙** 进入设置。

> [!NOTE]
> `.user.js` 是便于用户脚本管理器识别的文件扩展名；脚本内容与上传的原始 JS 完全一致。各平台和版本的 Via 对用户脚本接口、全屏模式支持可能不同，建议先在实际设备上测试。

### 其他脚本管理器

对于支持 `GM_getValue`、`GM_setValue` 及本脚本所用 Web API 的用户脚本环境，可以尝试导入 `.user.js` 文件。**兼容性未经过全平台验证**，不是对所有网站和设备的适配承诺。

## 缩略图预览机制

脚本优先尝试利用播放器已有的预览资源，而**不是从播放视频中实时截图**。识别逻辑主要包括：

1. 检查视频文本轨道及页面相关节点中可访问的 **WebVTT（`.vtt`）预览信息**。
2. 利用网站原有的预览节点与图片，学习**精灵图布局**和时间映射。
3. 对符合特征的布局使用**按域名保存的本地缓存**，并在当前视频对象上保留识别状态。
4. 在资源尚未加载时按间隔重试；确实无法识别时显示文字提示，而非承诺一定出现图片。

**请注意：** 如果站点没有提供预览图片，或者资源受跨域限制、请求鉴权、原生全屏播放器或站点自定义机制限制，缩略图可能无法显示。

## 兼容性与限制

- 主要针对网页中可访问的 **HTML5 `<video>`** 元素。不是所有站点、iframe、加密播放场景或系统原生全屏播放器都能接管。
- 脚本中包含对部分常见播放器控件结构的适配选择器，例如 Plyr、Video.js、DPlayer、ArtPlayer、xgplayer、JW Player、MediaElement.js 等；这**不意味着上述播放器的所有版本都已验证兼容**。
- iOS / Android 系统播放器、浏览器级全屏界面和网站自身的手势拦截可能优先于用户脚本，导致控制状态不完全同步。
- 仅对 `https://` 页面生效；不涵盖 HTTP 页面。
- 本版本**没有提供亮度调节开关或音量滑动控制**，请使用设备或浏览器自身的功能。
- 直播、时长未知或不可拖动的视频，进度操作可能不可用。

## 排查问题

**横屏后没有显示控制条？**

确认已启用脚本、页面是 HTTPS、视频已加载并且处于横屏。部分网页会把视频交给系统原生全屏播放器，这种情况下脚本无法保证覆盖系统控件。

**能拖动进度，但没有缩略图？**

打开 **设置 → 预览** 查看当前识别状态；若网站提供图片但识别不正确，可点击 **重新学习当前域名**。若网站没有预览源或资源无法访问，脚本无法凭空生成缩略图。

**与网站原有播放器冲突？**

在 **设置 → 预览 → 当前页面** 选择 **退出本页接管**。这会退出当前页面的脚本接管，不删除已学习的域名布局。

**旋转屏幕后预览失效？**

脚本实现了按视频保留识别状态及失败重试，但在页面重建视频节点、切换资源或播放器改版等情况下仍可能失效。可以重新播放、手动重新学习，或提交复现信息。

## 数据与权限

用户脚本头部声明了以下权限和作用范围：

```javascript
// @match  https://*/*
// @grant  GM_getValue
// @grant  GM_setValue
```

- 设置及域名预览布局保存在用户设备的 `GM_*` 存储或网页 `localStorage` 中。
- 脚本可能读取页面已经提供的视频、文本轨道及预览图片资源，并尝试请求页面发现的 VTT 文件。源码中没有配置独立的统计上报服务。
- 因为匹配范围是**全部 HTTPS 网站**，建议只从可信来源安装脚本，并定期检查源码变更。
